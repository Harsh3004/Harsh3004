**How WayScan works**  
A React Native app detects potholes with TensorFlow Lite and queues reports offline in WatermelonDB. A Flask backend groups nearby detections with DBSCAN, scores ticket priority, and automates the ticket lifecycle. City teams review tickets in a Next.js 16 dashboard with live updates via Server-Sent Events and a Groq-powered voice assistant.
